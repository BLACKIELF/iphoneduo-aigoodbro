## 使用

1. 选择地区、门店、型号、容量、颜色，添加监控任务。
2. 可选填写 Bark 或飞书/Lark 自定义机器人地址。开启机器人签名校验时再填密钥。保存设置不会发消息。
3. 点击“开始监控”。首次确认有货和之后真实无货转有货时提醒。临时查询错误不视为无货。
4. 关闭 Chrome 后后台继续运行。电脑需开机、登录当前 macOS 用户、联网且保持唤醒；睡眠期间不实时查询。
5. “立即检查”可在暂停时查询一轮并保持暂停，不发送外部提醒。“暂停”停止后续查询和提醒，已经送达的消息无法撤回。
6. 有货时点击任务的“官网”，自行核实、下单和付款。

关闭 Chrome 时，需要配置 Bark 或飞书/Lark 才能收到外部提醒；未配置时只记录库存日志。本版没有浏览器系统通知。

## 提醒和隐私

- 间隔支持30、60、120、300秒。
- Bark仅支持 `https://api.day.app/`；飞书/Lark仅支持其官方机器人HTTPS地址。
- 配置和密钥保存于本机后台状态文件及扩展本地缓存，不使用Chrome同步；它们不是加密保险箱。后台目录权限0700，状态及本机配对密钥权限0600，日志不包含通知密钥。
- 启动后，有货提醒会发送门店、型号、容量、颜色和官网商品链接到所配置渠道。
- HTTP和业务返回都成功才记录成功；各渠道独立，失败最多重试3次，每次至少间隔60秒且等待下一轮库存确认。

## 监控边界与卸载

Java 后台仅查询门店自提库存。自动加购和生成未付款订单由下方的浏览器模块负责，尚待实站验收；程序不执行付款，不保证配送预购成功。未知或缺失门店/SKU状态显示异常；ineligible显示“暂不可自提”。403/541表示官网限制；浏览器手动验证不会把Cookie共享给Java，不能保证解除限制。

503/429时后台按60、120、240、300秒逐步延长等待后重试，界面显示“等待重试”。查询故障不判成有货或无货，不触发库存变化提醒。不要连续点“立即检查”；等待下一次重试即可。503本身仍可能持续，此机制不代表官网接口已经恢复。

卸载前先在扩展中暂停。仅移除扩展不会停止已运行的Java服务。停止并取消当前登录服务可执行：

```bash
launchctl bootout "gui/$(id -u)/com.aigoodbro.apple-helper"
```

如要取消以后登录启动，再将上述专属plist移到废纸篓；随后移除Chrome扩展与专属NativeMessagingHosts/com.aigoodbro.apple_helper.json。保留项目和运行目录便于恢复；本安装器不会自动删除用户任务、日志或JDK。

## 自动购买（1016v3新增，实站尚未验收）

在“自动购买 · 邮寄”中选择型号、容量、颜色和最高总金额。勾选允许生成未付款订单并接受官网条款后，点击“启动自动购买”。未勾选时停在订单确认步骤。程序先检查购物袋；只有一个准确匹配的商品才继续。切换同款单件的颜色需要单独勾选允许更改颜色，购物袋包含其他商品时停止。

已实现的程序流程：检查购物袋 → 自动选配 → 加购物袋 → 进入结账 → 使用官网已有资料继续 → 核对总价/规格/数量/邮寄/支付宝 → 持久保存提交标记 → 提交一次 → 读取未付款回执或停在付款步骤。缺少资料、身份验证、未知页面会停止，补全后可点继续；已有提交标记时此按钮仅核对结果。程序不保存地址、电话、验证码或Cookie。

商品页明确无货时每30秒刷新等待；未知页面不当成无货。网页自动购买要求Chrome运行，Java常驻监控是独立功能。现有Java门店自提库存不能证明邮寄有货，因此不会混用两者结果。
