# AiGoodBro 品牌形象与设计规范 (Design Guidelines)

> 本文档规范 **AiGoodBro** 品牌吉祥物卡通形象、Chrome 扩展及跨端界面的视觉美学、排版、色彩及交互体验。

---

## 一、品牌卡通形象设定 (Character Identity)

当前正式人物参考采用 **无眼镜版设定 0921v3 / 0928v1**。全系列应用均统一使用卡通形象的半身头像或全身照，**停用奶油色双开门旧软件图标**。

                    │      AiGoodBro 形象      │
                    │   (无眼镜 · 亲切机灵)    │
                    └────────────┬────────────┘
                                 │
         ┌───────────────────────┼───────────────────────┐
         ▼                       ▼                       ▼
    【发型与面容】           【服饰与配色】           【下装与鞋履】

  • 深色眼睛+亲切微笑      • 左胸清晰 "Bro" 字标    • 裤腿自然垂坠不紧绷
  • 清爽面庞，无眼镜      • 红拉链、红袖口细节     • 纯白休闲运动鞋
                          • 内搭洁白纯棉 T 恤

### 1. 核心视觉识别点
- **头部**：黑色短发，顶部带自然灵动的微翘发束；双眼清澈有神，神情机智、亲切、富有探索精神；**严格不戴眼镜或墨镜**。
- **上装**：深天蓝与宝蓝拼色棒球/飞行员夹克，左胸规范印制白色 **Bro** 字样（严格为 Bro，不可写作 GB）；拉链与袖口点缀醒目正红，内衬洁白纯棉 T 恤。
- **下装与鞋**：深灰黑色宽松直筒长裤，裤腿在膝盖及裤脚留足余量，自然垂坠（不做紧身裤）；脚踩干净清爽的纯白色球鞋。
- **气质定位**：热心靠谱的科技好哥们，擅长钻研工具与自动化，愿意把复杂流程讲明白，带有一点轻松机敏的幽默感。

## 二、图标与组件尺寸规范 (Iconography)

扩展与界面图标由无眼镜版官方头像衍生制作，保证在各分辨率下的清晰度与锐利度：

| 规格 | 尺寸 (px) | 载体位置 | 视觉处理 |
|---|---|---|---|
| **Topbar Avatar** | 68×68 (Retina 136) | 扩展控制台顶部标题旁 | 圆形裁切，3px 白色实线高光描边，0 6px 18px 浅阴影 |
| **Store / Large Icon** | 128×128 | Chrome 应用商店、扩展详情页 | 正方形微圆角 (rx=24)，高保真头像呈现 |
| **Extension Management** | 48×48 | Chrome `chrome://extensions/` 列表 | 适配高像素密度显示，强化发型与蓝夹克辨识 |
| **Favicon / Browser Action** | 16×16 (32@2x) | 浏览器扩展栏挂载图标、标签页 Favicon | 精简轮廓高对比度输出，保证微缩状态可读 |

## 三、排版与字体规范 (Typography)

遵循 macOS / Apple 原生设计美学与现代中文排版标准：

### 1. 字体族声明
- **中英文主体**：统一优先调用苹果系统原生苹方 `PingFang SC`，后备 `-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`。
- **字重规定**：
  - **大标题 / 主题引导**：`PingFangSC-Semibold` / 字重 `600`，字距微收 `-0.04em`。
  - **分类标签 / 步骤标号**：字重 `800`，字母大写，字距舒展 `0.15em`。
  - **正文 / 表单标签 / 说明**：`PingFangSC-Regular` / 字重 `400`，行高 `1.6`。
  - **控制台日志 / 时间戳**：等宽字体族 `ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace`。

### 2. 严禁事项
- 严禁假粗体（通过 CSS text-stroke 或伪描边渲染的粗体）；
- 严禁假斜体及文字拉伸挤压；
- 严禁中英文混排丢失苹方原生标点间距。

## 四、色彩与状态规范 (Color System)

```
[ Primary Blue ]  #0877f9   ──   核心品牌蓝、操作主按钮、激活标号
[ Success Green ] #14853d   ──   有货状态 (#e7f7ec 底)、后台正常连接
[ Alarm Red ]     #cf1322   ──   持续响铃、紧急抢购、异常错误 (#fff1f0 底)
[ Warning Orange ]#a95000   ──   官网需验证、等待重试 (#fff0df 底)
[ Neutral Slate ] #676b73   ──   次级说明、时间戳、空状态提示
[ Clean Card ]    #ffffff   ──   高透白圆角卡片，阴影 0 18px 50px rgba(20,25,35,.08)
```

### 状态指示卡片 (Badges)
- **有货 / 直达准备就绪**：背景 `#e7f7ec`，字色 `#14853d`，高对比度圆角药丸胶囊。
- **持续响铃中**：背景 `#fff1f0`，外边框 `#ff4d4f` (带 1.2s 循环呼吸辉光动画)，字色 `#cf1322`。
- **接口限流 / 等待重试**：背景 `#fff0df`，字色 `#a95000`。
- **后台就绪 / 监听中**：`#14853d` 绿色动态小圆点。

## 五、声音与感官警报规范 (Auditory & Notification)

为实现极致的“刷到库存立即响应”，系统设计了双重声音感知通道：

1. **浏览器前端 Web Audio 持续警报**
   - **合成波形**：无损纯净 Sine 正弦波振荡器，避免爆音，采用平滑 ExponentialRamp 增益包络。
   - **和弦音阶**：经典的 3 音递增上行和弦（C6 `1046.5Hz` -> E6 `1318.5Hz` -> G6 `1568.0Hz`）。
   - **节奏频率**：每秒循环鸣响，前端顶部常驻显眼红色脉冲条及 **🔕 停止响铃** 按钮，直到用户手动停止或完成下单。
2. **操作系统原生硬件扬声器鸣响**
   - **macOS**：通过系统底层音频管道调用 `/System/Library/Sounds/Glass.aiff`。
   - **Windows**：通过 PowerShell `[console]::beep(1200, 400)` 激发主板与扬声器蜂鸣。
   - 即使关闭浏览器标签页，Java 守护进程也能在本地鸣响，并同步发送 Bark / 飞书推送。

## 六、交互流规范：一键直达与自动跳转

当库存探测结果由 `available: false` 变为 `available: true` 时：
1. **自动聚焦**：立即前台激活 Apple 购买标签页并置顶窗口；
2. **自动化推进**：快速自动选配容量、颜色、加入购物袋、穿透访客模式并选定门店最早自提时段；
3. **安全边界**：自动化停在“准备下单了吗？”（订单确认页面），严禁静默代扣支付，由用户亲自核对最终金额并点击下单。
